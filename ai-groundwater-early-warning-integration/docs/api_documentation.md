# API

`GET /health`, `/api/data/summary`, `/api/data/observations`, `/api/locations`, `/api/groundwater/current`, `/api/groundwater/history/{location_id}`, `/api/predictions`, `/api/stress/current`, `/api/anomalies`, `/api/alerts`, `/api/gis/geojson`, `/api/models`, and `/api/reports` are implemented. See live OpenAPI docs at `/docs`. Artifact-dependent endpoints deliberately return 404 until their producing pipeline ran.
